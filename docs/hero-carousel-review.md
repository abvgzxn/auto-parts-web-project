## Визуальная часть и React

Светлая композиция с тёмно-синим текстом, голубым полем справа, диагональю и тематическими знаками капли, снежинки и энергии. Это временная авторская SVG-графика, а не изображение товара или этикетки. Названия LUKOIL и АКОМ набраны обычным текстом, фирменные логотипы не имитируются. На телефоне текст, CTA, графика и управление идут последовательно.

Сохранены useState, циклические обработчики, интервал 6 секунд, очистка таймера, подписка на изменение prefers-reduced-motion. Ручное управление и фокус на CTA останавливают таймер; кнопка «Продолжить» возобновляет его, если системная настройка разрешает автопрокрутку. Слайды не анимируются.

Все слайды расположены в одной ячейке CSS Grid: самый высокий текст резервирует высоту. Неактивные слайды используют visibility:hidden, inert и aria-hidden. При автопрокрутке aria-live выключен. Кнопки имеют зоны 44 × 44 px и видимый фокус. H1 единственный, заголовки слайдов — H2.

Карусель остаётся единственным клиентским компонентом Hero. Новых зависимостей нет. Header, секции, контакты, JSON-LD, metadata, конфигурация деплоя не изменены.

## Фотографии и права

Ни одно внешнее фото не скачано и не опубликовано: подтверждённого разрешения на использование нет. Наличие товара в магазине не подтверждает права на фотографии производителя.

| АКОМ | [Официальная линейка АКОМ](https://akom.ru/catalog/starter/akom.html), в том числе АКОМ 60 | Разрешение для сайта Wellcar не подтверждено. Только кандидат; точная модель товара магазина не подтверждена. Нужны согласованные материалы или фото заказчика. |

Текущий публичный текст жидкости: «Незамерзающая жидкость уже в наличии в Wellcar. Чистое стекло и хороший обзор даже в мороз». Заголовок и акцент сохранены по заданию.

Для замены графики: сохранить разрешённое фото в `public/images/hero/`, добавить существующий локальный путь `imageSrc` и точный `imageAlt` в соответствующий слайд. Необязательные поля не содержат фиктивных путей. next/image использует object-fit:contain, фиксированную область и sizes; фотография появляется только у активного слайда. Первый слайд загружается eager, остальные — lazy. Не обрезать и не растягивать упаковку; оптимизировать WebP с проверкой читаемости этикетки.

## Проверки

- `npx tsc --noEmit`: успешно.
- `npm run lint`: успешно.
- `npm run build`: успешно; статическая production-сборка.
- Локальный production-сервер: `/carousel-preview` возвращает HTTP 404.
- Production Chromium, 390 px, CPU ×4, сеть 1,6 Мбит/с и задержка 150 мс: LCP 724 мс, CLS 0, передано JavaScript 147 120 байт. Это один локальный лабораторный замер, а не Lighthouse или полевые метрики; он не учитывает задержки хостинга.
- В production проверена пауза при фокусе CTA: через 6,2 секунды слайд остался прежним.
- `npm run test:e2e`: 30 успешно, 2 штатно пропущены (мобильное меню в desktop-профиле).
- Проверены 320, 390, 768, 1024, 1280, 1440 px: нет горизонтального переполнения, высота карусели одинакова для трёх слайдов, доступны CTA и кнопки.
- Проверены автопрокрутка, пауза/возобновление, циклическая навигация, индикаторы и динамическое изменение reduced motion.
- Таймерные тесты начинают отсчёт после взаимодействия с кнопками, чтобы дождаться гидратации. Тест изменения reduced motion ожидает браузерное событие перед продвижением виртуального времени.

Первоначальные sandbox-запуски не могли открывать локальные порты. Для браузерных проверок использован установленный Playwright: CLI agent-browser в окружении отсутствует. Скриншоты проверены визуально.

## Ограничения

До получения фотографий Hero использует временную графику. Температура жидкости требует подтверждения. Лабораторные показатели производительности не являются полевыми Core Web Vitals; после замены изображений производительность необходимо перепроверить. Коммит, push и публикация не выполнялись.
